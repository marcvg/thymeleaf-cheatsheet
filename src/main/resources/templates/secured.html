REST API (App Reg 1)

The GET /api/hello endpoint is separately secured with a Bearer token issued to the REST API app registration. It is not affected by this SSO session. 

token=$(az account get-access-token \
  --resource api://<rest-api-client-id> \
  --query accessToken -o tsv)

curl -H "Authorization: Bearer $token" \
     http://localhost:8080/api/hello
