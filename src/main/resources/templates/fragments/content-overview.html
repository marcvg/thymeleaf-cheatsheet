Overview

This page demonstrates Thymeleaf fragments.

How fragments work

1. Define a fragment:
<header th:fragment="header(pageTitle)">
  <nav>
    <strong th:text="${pageTitle}"></strong>
  </nav>
</header>

2. Use th:replace (replaces host tag):
<div th:replace="~{fragments/header
    :: header(#{fragments.title})}">
</div>

3. Use th:insert (keeps host tag):
<div th:insert="~{fragments/footer :: footer}">
</div>
Key differences:

th:replace
  Replaces the entire host element
  with the fragment content.

th:insert
  Inserts the fragment as a child
  of the host element.

Parameterized fragments:
  th:fragment="name(param1, param2)"
  Pass values when including:
  ~{template :: name(val1, val2)}
