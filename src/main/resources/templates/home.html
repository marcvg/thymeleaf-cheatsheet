5. Literal Substitutions (Pipe Syntax)

Pipe syntax (clean):

Hello, John Doe!

Concatenation (ugly):

Hello, John Doe!

Pipe syntax |...| (preferred):
<p th:text="|Hello, ${firstName} ${lastName}!|">
</p>

String concatenation (avoid):
<p th:text="'Hello, ' + ${firstName}
    + ' ' + ${lastName} + '!'">
</p>

6. Link URL Expressions @{...}

  • Simple: @{/fragments}
  • With path variable: @{/fragments/{tab}}
  • With query params: @{/path(params)}
<a th:href="@{/fragments}">Simple</a>

<a th:href="@{/fragments/{tab}(tab='customers')}">
  Path variable
</a>

<a th:href="@{/fragments(
    tab='customers',sort='name')}">
  Query params
</a>

7. Switch / Case

Order status: Pending Shipped Delivered Unknown

(Model value: STATUS — try changing it in the controller) 
<span th:switch="${orderStatus}">
  <mark th:case="'PENDING'">Pending</mark>
  <mark th:case="'SHIPPED'">Shipped</mark>
  <mark th:case="'DELIVERED'">Delivered</mark>
  <span th:case="*">Unknown</span>
</span>

Note: th:case="*" is the default case.

8. Local Variables (th:with) & Elvis Operator

Nickname: fallback

First name: fallback

Local variable with th:with:

  <p th:text="${fullName}"></p>
</div>

Elvis operator (?:) for null defaults:

</span>

9. Inline Expressions

Inline text: [[${firstName}]] [[${lastName}]]

Works without th:inline too: [[${todaysDate}]]

Inline text (escaped):
<p th:inline="text">
  Hello [[${firstName}]] [[${lastName}]]
</p>

Without th:inline (also works):
<p>Today is: [[${todaysDate}]]</p>

Inline JavaScript:
<script th:inline="javascript">
  var user = /*[[${firstName}]]*/ "default";
</script>

Note: [[...]] is escaped, [(...)]] is unescaped.

12. Working POST Form with Toast Feedback

Template (form with POST action):
<form th:action="@{/}"
      th:object="${searchFilter}"
      method="post">
  <input type="text" th:field="*{firstName}">
  <button type="submit">Submit</button>
</form>

Toast (Pico <dialog> with flash attribute):
<dialog th:if="${toastMessage}" open>
  <article>
    <header>
      <button aria-label="Close" rel="prev"
        onclick="this.closest('dialog').close()">
      </button>
      <p><strong>Notification</strong></p>
    </header>
    <p th:text="${toastMessage}"></p>
  </article>
</dialog>

Controller:
@PostMapping("/")
String handlePost(@ModelAttribute SearchFilter filter,
    RedirectAttributes redirect) {
  redirect.addFlashAttribute("toastMessage",
      "Filter applied for: " + filter.getName());
  return "redirect:/";
}

13. Pico Tables

Note: iterStat.count starts at 1, iterStat.index starts at 0. Also available: .size, .even, .odd, .first, .last 
<table>
  <thead>
    <tr>
      <th scope="col">#</th>
      <th scope="col">Name</th>
      ...
    </tr>
  </thead>
  <tbody>
    <tr th:each="c, iterStat : ${customers}">
      <th th:text="${iterStat.count}">1</th>
      <td th:text="|${c.firstName} ${c.lastName}|">
      </td>
      <td>
        <mark th:if="${c.active}">Active</mark>
      </td>
    </tr>
  </tbody>
</table>

Iteration status variable (iterStat):
.index  (0-based)    .count (1-based)
.size   (total)      .current (element)
.even   .odd         .first   .last
